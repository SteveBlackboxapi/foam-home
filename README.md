## Live preview

User site (already publishing): https://steveblackboxapi.github.io/

This project URL after Pages is enabled: https://steveblackboxapi.github.io/foam-home/

## Enable Pages on this repo

1. Open https://github.com/SteveBlackboxapi/foam-home/settings/pages
2. Source: **GitHub Actions**
3. Wait for the `Deploy Pages` workflow, then open the project URL above.

Single-page site. Photos are SVG-wrapped JPEGs in `assets/` so they do not truncate on upload.
